4. LEAK DETECTION
==================================================

Implement rule-based leak detection.

Do NOT call this machine learning or AI.

Initial thresholds:

NORMAL:
flow_rate < 12 AND pressure >= 2.5

WARNING:
flow_rate >= 12 OR pressure < 2.5

LEAK:
flow_rate >= 18 OR pressure < 2.0

Make these thresholds configurable in one place so they can easily be changed later.

When a LEAK condition is detected:

1. Create an ALERT.
2. Set severity = CRITICAL.
3. Set pipeline status = LEAK.
4. Store the flow and pressure values.
5. Include the pipeline/sensor location.
6. Return the alert information in the API response.

When WARNING is detected:

1. Create a WARNING alert.
2. Set pipeline status = WARNING.

When readings return to normal:

Set pipeline status back to NORMAL where appropriate.
