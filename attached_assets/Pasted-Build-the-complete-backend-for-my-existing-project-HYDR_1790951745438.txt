LEAK DETECTION
==================================================

Implement rule-based leak detection.

IMPORTANT:

Do NOT call this Machine Learning or AI.

Use configurable thresholds.

Example:

NORMAL:

Flow < 12 L/min
Pressure >= 2.5 bar

WARNING:

Flow >= 12 L/min
OR
Pressure < 2.5 bar

LEAK:

Flow >= 18 L/min
OR
Pressure < 2.0 bar

Make thresholds configurable through settings.

Return:

status
severity
reason

Example:

{
    "status": "LEAK",
    "severity": "CRITICAL",
    "reason": "Abnormally high flow and low pressure"
}
